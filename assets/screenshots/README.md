# اسکرین‌شات‌ها

تصاویر صفحات برنامه اینجا می‌نشینند و از دو جا خوانده می‌شوند:

1. `index.html` — آرایه‌ی `SHOTS` را پر کنید:
   ```js
   const SHOTS = [
     { src:'assets/screenshots/dashboard.png', fa:'داشبورد عملیاتی', en:'Operational dashboard' },
   ];
   ```
   تا وقتی این آرایه خالی باشد، بخش «نماهایی از سامانه» به‌طور خودکار پنهان است.

2. `README.md` و `README.en.md` — با نشانه‌گذاری معمولی مارک‌داون.

## قاعده‌ها

- عرض ۱۴۴۰ پیکسل، فرمت PNG، حجم هر فایل زیر ۵۰۰ کیلوبایت.
- **هیچ داده‌ی واقعی مشتری در تصویر نباشد** — نام افراد، شماره پرسنلی،
  شماره‌ی نامه، مبالغ. این مخزن عمومی است.
- از هر دو حالت فارسی و انگلیسی عکس بگیرید تا دوزبانگی دیده شود.
