دوام چیست

یک سامانه‌ی CMMS/PMS تحت وب که کل چرخه‌ی نگهداری و تعمیرات یک شرکت حفاری را می‌گرداند — از برنامه‌ی PM و دستور کار تا نامه‌نگاری اداری، انبار، تدارکات و امور کارکنان.

🛠 نگهداری و تعمیرات

قلب سامانه — همان چیزی که تکنسین و سرپرست نت هر روز با آن کار می‌کنند.

  • درخت تجهیزات هر دکل، با ایمپورت از اکسل
  • برنامه‌ی PM روزانه/هفتگی/ماهانه بر تقویم شمسی
  • تولید خودکار شبانه‌ی دستور کار
  • قفل «دلیل تأخیر» روی کار عقب‌افتاده
  • خرابی، کار برنامه‌ریزی‌نشده، گزارش روزانه

📦 زنجیره‌ی تأمین

از درخواست کالا تا تحویل و ثبت دارایی.

  • انبار و موجودی، با اتصال به API انبار سازمان

  • تنخواه و اموال

نصب

کل نصب از طریق API گیت‌هاب انجام می‌شود — هیچ فایلی دستی آپلود نمی‌شود.

گرفتن اسکریپت نصب

اسکریپت مستقیم از مخزن خصوصی و با توکن شما دانلود می‌شود.

export DAVAM_GH_TOKEN='توکنی-که-گرفته‌اید'

curl -fsSL \
  -H "Authorization: Bearer $DAVAM_GH_TOKEN" \
  -H "Accept: application/vnd.github.raw" \
  https://api.github.com/repos/davam-automation/davam/contents/davam.sh \
  -o davam.sh

اجرای منو

منوی نصب و مدیریت باز می‌شود؛ گزینه‌ی ۱ (داکر) یا ۲ (نصب مستقیم).

bash davam.sh

تمام

اسکریپت پیش‌نیازها را نصب می‌کند، آخرین نسخه را می‌گیرد، پسورد دیتابیس و کلید امنیتی را تصادفی می‌سازد، فایروال را تنظیم می‌کند و در پایان آزمون پذیرش می‌گیرد و آدرس و رمز ورود را چاپ می‌کند.

کانال اختصاصی مشتری: هر نصب می‌تواند کانال خودش را داشته باشد — UPDATE_CHANNEL برای نسخه‌های اختصاصی و UPDATE_PIN به‌عنوان سقف نسخه، برای مشتری‌هایی که باید روی نسخه‌ی تأییدشده بمانند.

What Davam is

A web-based CMMS/PMS that runs the entire maintenance cycle of a drilling contractor — from PM schedules and work orders to official correspondence, warehouse, procurement and HR.

🛠 Maintenance

The core — what technicians and supervisors touch every day.

  • Per-rig equipment tree, importable from Excel
  • Daily / weekly / monthly PM plans on the Jalali calendar
  • Nightly automatic work-order generation
  • Mandatory delay reason on overdue work
  • Failures, unplanned work, daily reports

📦 Supply chain

From material request to delivery and asset registration.

  • Inventory, with a corporate warehouse API connector
  • Procurement and purchase orders
  • Petty cash and asset register

✉️ Administration & HR

The work that used to live on paper and in email.

  • Letters with letterhead, routing and signatures
  • Document library and inbox
  • Leave, travel, payslips, tickets
  • Multi-step approval engine

📊 Management & reporting

The picture a manager needs to decide.

  • Operational dashboard and KPIs
  • Progress charts by rig and department
  • Excel export from every list
  • Full audit log

🌐 Bilingual, RTL-native

Persian right-to-left and English left-to-right, switchable at runtime — including printed and PDF output.

🔐 Access & security

JWT and bcrypt, role-based access, and per-rig data isolation — each user sees only their own rig's data.

Installation

The whole install runs through the GitHub API — nothing is uploaded by hand.

Fetch the installer

Downloaded straight from the private repository with your token.

export DAVAM_GH_TOKEN='your-token-here'

curl -fsSL \
  -H "Authorization: Bearer $DAVAM_GH_TOKEN" \
  -H "Accept: application/vnd.github.raw" \
  https://api.github.com/repos/davam-automation/davam/contents/davam.sh \
  -o davam.sh

Run the menu

Pick option 1 (Docker) or option 2 (bare-metal).

bash davam.sh

Done

The script installs prerequisites, pulls the latest release, generates a random database password and secret key, configures the firewall, runs an acceptance check, and prints the URL and login.

Updating

In all three routes the database, attachments and .env are preserved, and a backup is taken automatically before every update.

🖱 From inside the app

Settings → System update: the new version, its changelog, and one install button. Enable it once on the server:

bash davam.sh agent-install

📋 From the menu

bash davam.sh, then option 4 (latest) or 5 (specific version). The install method is detected automatically.

⌨️ From the command line

bash davam.sh check
bash davam.sh update
bash davam.sh update 6.31.0
bash davam.sh changes 6.30.0
Per-customer channels: each installation can follow its own channel — UPDATE_CHANNEL for customer-specific builds and UPDATE_PIN as a version ceiling, for customers who must stay on an approved release.
Why the API never touches the server itself: the backend only records a request; an agent on the host carries it out. If the API could reach Docker or systemd, any API compromise would become root access.

Security

Secure from minute zero

The database password and secret key are generated randomly per installation — no default value ever reaches production.

Layered access

JWT and bcrypt, admin/manager/user roles, and per-rig data isolation. Audit log for sensitive operations.

Small attack surface

The backend listens on an internal port only; external traffic goes through nginx. The repository token is read-only and single-repo.

HTTPS in one command

bash davam.sh ssl example.com — Let's Encrypt certificate with automatic renewal.
